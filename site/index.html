Três jeitos de usar, troca num clique

O app Appearance muda entre Windows, macOS e Ubuntu sem terminal. Estas são as miniaturas reais usadas nele.

Windows

Barra embaixo com menu iniciar. Vem ativado por padrão.

macOS

Barra em cima e dock embaixo no centro.

Ubuntu

Barra lateral esquerda, estilo original.

Atualiza sem formatar

Versões menores chegam pelo app Atualização do Sistema.

  1. O sistema avisa sozinhoUma checagem semanal procura releases novos no GitHub.
  2. Você escolhe a versãoUma janela lista o que mudou. Nada acontece sem confirmar.
  3. Aplica com backup e volta atrásAntes de trocar, salva suas configs. Se algo vier incompleto, restaura e aborta em vez de quebrar.

Requisitos

  • PC ou notebook 64 bits com 4 GB de RAM (roda com 2 GB, devagar)
  • 25 GB livres no disco e um pendrive de 8 GB pra gravar a ISO
  • Secure Boot desligado na BIOS para dar boot no pendrive
  • Internet na hora de instalar os pacotes de idioma e drivers
